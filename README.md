# Describe Your Ex in One Word

Entry for the [make.fun bounty "Describe Your Ex in One Word"](https://make.fun/c/u-puan-describe-your-ex-in-one-word-9fc6ebe7/).

`main.py` writes exactly one word — **Recalled** — to `/output/entry.txt`.

Like a defective product: recalled, returned, done.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
